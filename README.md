# Task 16 – Enterprise Multi-Tenancy & RBAC

## Developed By

*Ritu Raj Singh*

## Project Overview

This project focuses on *Enterprise Multi-Tenancy & Role-Based Access Control (RBAC)* analytics.

The main objective is to create tenant-wise analytics while maintaining strict data isolation between different tenants.

## Objectives

* Perform tenant-wise analytics and reporting.
* Analyze users, events, regions, industries and statuses.
* Create aggregate benchmarks across tenants.
* Validate tenant and user-level data isolation.
* Check for possible cross-tenant data leakage.
* Prepare the cleaned data for Tableau visualization.

## Tools Used

* Python
* Pandas
* NumPy
* Microsoft Excel
* Tableau
* GitHub

## Data Processing

The dataset was cleaned and validated using Python. The analysis included:

* Missing-value checking
* Duplicate checking
* Data-type validation
* Tenant consistency validation
* User-to-tenant isolation checking
* Event-to-tenant isolation checking
* Tenant-wise analysis
* Event and status analysis
* Region and industry analysis
* Monthly analysis
* Aggregate benchmarking

## Key Analysis

The Python analysis provides:

* Tenant-wise records, events and amount
* User-wise activity
* Event-type analysis
* Region-wise analysis
* Industry-wise analysis
* Success and failure analysis
* Monthly activity
* Tenant isolation validation
* Cross-tenant leakage validation

## Visualization

The cleaned dataset is used in *Tableau* to create a consolidated dashboard containing KPIs and important tenant-level insights.

## Conclusion

The project demonstrates how multi-tenant data can be analyzed while maintaining proper tenant-level isolation. Python was used for data preparation, validation and analysis, while Tableau was used for visualization and dashboard reporting.
